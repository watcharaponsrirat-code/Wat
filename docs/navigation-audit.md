# เลือกกิจกรรมได้อิสระ

นักเรียนเลือกเนื้อหา แล็บ เกมทั้งสาม แบบฝึกทั้งสาม และข้อสอบได้จากปุ่มบนแถบกิจกรรมทุกหน้า ลำดับเดิมใช้เป็นคำแนะนำ ไม่ใช่เงื่อนไขล็อกปุ่ม การไปกิจกรรมอื่นไม่ให้ XP หรือสถานะผ่านโดยอัตโนมัติ

- ป้ายแยกยังไม่ทำ เปิดแล้ว ทำแล้วแต่ยังไม่ผ่าน และผ่านเกณฑ์ เนื้อหาใช้คำว่าอ่านจบแล้ว
- แบบฝึกยังใช้เป้าหมายถูกครบ 100% เพื่อรับสถานะผ่าน แต่ไปต่อได้โดยไม่ต้องผ่านก่อน
- ข้อสอบยังผ่านที่ 60% เริ่มสอบก่อนได้ มีคำแนะนำให้เตรียมตัว และทำใหม่ได้
- หน้าผลลัพธ์ก่อนสอบแสดงว่ายังไม่มีผลสอบ ไม่แสดงคะแนนศูนย์เสมือนสอบตก
- เมื่อเลือกกลับเข้าบท จะกลับไปกิจกรรมล่าสุด รวมถึงผู้ที่เคยผ่านข้อสอบแล้ว
- แบบฝึกและผลสอบมีปุ่มอ่านหัวข้อที่ตอบผิด โดยเก็บคำตอบไว้ขณะกลับไปอ่าน
- แถบกิจกรรมขึ้นบรรทัดใหม่บนมือถือ และไม่ตรึงทับพื้นที่อ่านเนื้อหา

## การตรวจ

`tests/navigation-regression.mjs` ตรวจการเลือกครบ 10 หน้าใน 40 บท การข้ามกิจกรรมโดยไม่รับสถานะผ่าน การกลับไปอ่านหัวข้อ การเก็บคำตอบข้อสอบเมื่อสลับหน้าและโหลดใหม่ และการสอบก่อนทำกิจกรรมที่คะแนน 55%/60%

ชุดทดสอบแบบฝึก 120 ชุด เกม 120 กระดาน และแล็บ 40 บทผ่านหลังแก้ไข โดยปรับเงื่อนไขการทดสอบให้การไปต่อเป็นอิสระจากสถานะผ่าน

ตรวจใน Microsoft Edge แบบ headless: ปุ่มเลือกครบ 10 หน้าไม่ล้นจอที่ความกว้าง 1366, 390 และ 320 พิกเซล ตรวจภาพมือถือ 390 พิกเซล รวมถึงการเก็บร่างแล็บ การข้ามเกม และปุ่มอ่านทบทวนที่เก็บคำตอบไว้ ไม่พบข้อผิดพลาด JavaScript ระหว่างการตรวจนี้ Browser ในแอปไม่พร้อมเชื่อมต่อจึงใช้ Edge แทน

```sh
node tests/navigation-regression.mjs
node tests/game-regression.mjs
node tests/lab-regression.mjs
```

ชุดทดสอบ navigation เรียกชุด exercise ด้วย การตรวจผ่านไม่ใช่การรับรองความถูกต้องเชิงวิชาการของข้อคำถามทุกข้อ
