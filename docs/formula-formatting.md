# รูปแบบสมการในบทเรียน

วันที่ 9 ตุลาคม 2569

ปรับการแสดงสมการให้เป็นรูปแบบเดียวกับเนื้อหาแบบเรียน: ใช้ชื่อปริมาณภาษาไทย เศษส่วนที่มีเส้นคั่นเศษ/ส่วน เครื่องหมายคูณ × เลขยกกำลัง ตัวห้อย และหน่วยที่สัมพันธ์กับสูตร

## ขอบเขต

- สมการหลักเดิม 17 หัวข้อ ครบทุกหัวข้อที่มี formula ในข้อมูลบทเรียน
- เพิ่มกล่องสมการให้ความสัมพันธ์ที่มีอยู่แล้วในคำอธิบายอีก 6 หัวข้อ: ความเร็วเฉลี่ย ความร้อนกับอุณหภูมิ การหลอมเหลว/แข็งตัว การกลายเป็นไอ/ควบแน่น สมดุลความร้อน และความต่างศักย์
- รวม 23 หัวข้อ ครอบคลุมความหนาแน่น ความเข้มข้นร้อยละทั้งสามแบบ ความร้อน การเคลื่อนที่ โมเมนต์ งาน กำลัง พลังงาน คลื่น แสง และไฟฟ้า
- จัดรูปสมการและการหารตัวเลขที่แทรกในคำอธิบาย ตัวอย่าง แบบฝึก ข้อสอบ เฉลยย้อนหลัง เกม และคำอธิบาย/ผลของแบบจำลองด้วยตัวแสดงผลร่วมกัน
- ภาพต้นฉบับข้อสอบ O-NET และภาพประกอบยังเป็นภาพเดิม การปรับนี้เป็นข้อความและสมการที่เว็บสร้างขึ้น ไม่แก้ข้อความในไฟล์ภาพหรือ geometry ของแบบจำลอง

## หลักการเขียน

ร้อยละโดยมวลต่อปริมาตรใช้มวลของตัวละลาย (g) เป็นเศษ และปริมาตรของสารละลาย (cm³) เป็นส่วน แล้วคูณ 100 พร้อมระบุว่า 1 cm³ = 1 mL ใช้ปริมาตรของสารละลายสุดท้าย ไม่ใช้ปริมาตรของตัวทำละลาย

สูตรที่ใช้สัญลักษณ์มีบรรทัดภาษาไทยก่อน ตามด้วยสัญลักษณ์และความหมายพร้อมหน่วย เช่น กำลัง = งาน/เวลา และ P = W/t ระบุความต่างระหว่าง W ที่เป็นตัวแปรงานกับหน่วยวัตต์ ส่วน Q ในเรื่องความร้อนและประจุไฟฟ้าอธิบายตามบริบท

ระบุเงื่อนไขของสูตรเมื่อจำเป็น เช่น งาน W = Fs ใช้แรงคงตัวในทิศการกระจัด กฎของโอห์มใช้กับตัวนำโอห์มิกในสภาพคงที่ และสมดุลความร้อนต้องรวมพลังงานของทุกส่วนที่แลกเปลี่ยนกันภายในขอบเขตที่กำหนด

หน่วยอย่าง m/s², g/cm³ และข้อความตัวเลือกที่ใช้เครื่องหมาย / ไม่ถูกตีความเป็นสมการโดยอัตโนมัติ การจัดรูปในข้อความใช้เฉพาะรูปสมการที่รู้จักและการหารตัวเลขที่ไม่กำกวม กรณีที่ยังไม่รู้จักคงข้อความที่ escape แล้วไว้ เพื่อรักษาความหมายเดิม

## โครงสร้าง

- assets/content/formulas.js: รายการสมการตามรหัสหัวข้อ ตัวแสดงเศษส่วน/ตัวห้อย/เลขยกกำลัง และตัวจัดรูปสมการในข้อความ
- assets/content/formulas.css: การจัดวางร่วมกัน รองรับจอแคบและการขึ้นบรรทัดระหว่างพจน์
- assets/content/reader-functions.js: ใช้ตัวแสดงสมการและจัดรูปตัวอย่างในหน้าอ่าน
- index.html: โหลดไฟล์ร่วมกัน และจัดรูปเฉพาะข้อความที่แสดงในโจทย์ ตัวเลือก และเฉลย
- assets/games/engine.js และ assets/simulations/engine.js: จัดรูปเฉพาะข้อความ HTML ที่ผู้เรียนเห็น
- สมการมี role="math" และข้อความทดแทนสำหรับการอ่านตามลำดับ

## การรักษาคะแนนและข้อมูล

ไม่แก้ข้อความคำตอบในคลัง ไม่เปลี่ยน data-ex-o/data-exam-choice และไม่เปลี่ยนวิธีเปรียบเทียบคำตอบ ข้อมูลข้อสอบและคำตอบที่บันทึกเดิมจึงยังใช้ต่อได้ ไม่เพิ่มรุ่นคลังเพราะเป็นการจัดรูปการแสดงผล

## การตรวจ

- tests/formula-regression.mjs: ครบ 23 หัวข้อและ 17 สูตรเดิม ตรวจเศษ/ส่วน หน่วย ตัวห้อย เลขยกกำลัง การคงข้อความที่ไม่ใช่สมการ การ escape และข้อมูลต้นฉบับที่ไม่เปลี่ยน
- tests/formula-browser.mjs: 69 กรณี (23 หัวข้อ × 1366/390/320 px), ตรวจเส้นเศษส่วน ตำแหน่งเศษเหนือส่วน ไม่มีการตัดหรือล้นกรอบ และบันทึกภาพตัวอย่าง
- ทดสอบตอบแบบฝึกผ่านปุ่มจริงได้ 100% เฉลยแสดงสมการ และคำตอบเดิมไม่เปลี่ยนหลังโหลดหน้าใหม่
- เพิ่ม formula-regression ใน GitHub Actions เพื่อป้องกันสมการหลักหลุดจากตัวแสดงผลร่วมกัน

ผลรอบสุดท้าย: การทดสอบสมการ เกม แบบฝึก การนำทาง การย้ายข้อสอบ และแบบจำลองผ่าน ตรวจหน้าจอครบ 1,200 กรณีและภาพบทเรียน 302 ภาพ ไม่มี JavaScript error หรือแนวนอนล้น ชุดเผยแพร่ผ่านทั้ง build, deployment-regression และ Chrome บน project subpath
