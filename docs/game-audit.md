# เกมวิทยาศาสตร์ตามเนื้อหาบทเรียน

## ขอบเขต

- ครบ 40 บท บทละ 3 เกม รวม 120 กระดาน
- แต่ละบทมีเกมเฉพาะเรื่อง เกมเปิดการ์ดแนวคิด–ตัวอย่าง 4 คู่ และภารกิจตัดสินใจจากสถานการณ์
- สลับเกมแรกระหว่างเกมเฉพาะเรื่องกับเกมเปิดการ์ด เพื่อไม่ให้เริ่มทุกบทเหมือนกัน
- ใช้สถานการณ์ที่เขียนไว้เดิมใน `assets/games/content.js` สำหรับ ม.1 และเพิ่มสถานการณ์ของ ม.2–ม.3 ใน `catalog.js`

| กลไก | ตัวอย่างเนื้อหา |
| --- | --- |
| เปิดการ์ดความจำ | เชื่อมแนวคิดกับตัวอย่างของบทนั้น |
| เรียงเส้นทาง | การหมุนเวียนเลือด ทางเดินหายใจ การสืบพันธุ์พืช |
| จัดหมวดหมู่ | ธาตุและสารประกอบ การถ่ายโอนความร้อน การอนุรักษ์ |
| เลือกหลักฐานหลายใบ | ออกแบบการทดลอง ประเมินข่าววิทย์ และความเสี่ยง |
| ปรับค่าเพื่อถึงเป้าหมาย | ความหนาแน่น ความเข้มข้น คาน คลื่น พลังงาน |
| ตารางพุนเนตต์ | Aa × Aa และการแยก A ออกจาก a |
| สวิตช์วงจรขนาน | สวิตช์หลักและแขนง ควบคุมหลอด A/B |
| ต่อสายใยอาหาร | ลูกศรจากอาหารไปยังผู้กิน ลบและแก้เส้นได้ |
| ภารกิจสถานการณ์ | ใช้แนวคิดตัดสินใจ พร้อมคำใบ้และเหตุผลหลังตอบ |

## การจัดเก็บและการปลดล็อก

`engine.js` ใช้ progress เดิมของเว็บไซต์ ไม่สร้างฐานข้อมูลใหม่ คำตอบ ตำแหน่งการ์ด เส้นเชื่อม ค่าที่ปรับ คำใบ้ และผลตอบกลับคงอยู่หลังโหลดหน้าใหม่

เกมใหม่ใช้ state version 4 โดยเปลี่ยนเฉพาะกระดานที่เป็นรูปแบบเก่า คงสถานะที่เคยผ่าน จำนวนครั้ง XP ข้อสรุปแล็บ และผลสอบเดิมไว้ ผู้ที่เคยผ่านยังไปขั้นถัดไปได้ หากเลือกเล่นใหม่ จะเริ่มกระดานใหม่และต้องทำเกมขั้นนั้นให้ผ่านอีกครั้ง แต่ไม่หัก XP ที่ได้รับแล้ว

ตอบผิดไม่ปลดล็อก ต้องสำเร็จครบทั้งกระดานก่อนผ่าน ความสำเร็จไม่เพิ่ม XP ซ้ำจากการกดตรวจซ้ำ ภารกิจแสดงเหตุผลค้างไว้ให้อ่านก่อนกดไปต่อ เกมไม่มีเวลานับถอยหลัง และทุกกลไกใช้ปุ่มหรือช่องกรอกมาตรฐานที่เข้าถึงด้วยแป้นพิมพ์ได้

หากเปลี่ยนโครงสร้าง state หรือความหมายคำตอบในอนาคต ให้เพิ่ม VERSION ใน `engine.js` และตรวจการย้ายข้อมูลเก่าอีกครั้ง

## ผลการตรวจ

- `tests/game-regression.mjs`: เล่นครบ 120 เกมผ่าน event handlers ตรวจคำตอบผิด/กระดานไม่ครบ การเล่นต่อหลังโหลดใหม่ การสุ่ม การปลดล็อก การเล่นใหม่ และการย้ายความคืบหน้าเดิม
- `tests/lab-regression.mjs`: ผ่านทั้ง 40 บท หลังเชื่อมเกมใหม่
- Microsoft Edge แบบ headless: เล่นผ่านปุ่มจริงครบ 9 กลไก รวมการใช้แป้นพิมพ์ปรับค่า
- ตรวจ DOM ของทั้ง 120 กระดาน ที่หน้าจอกว้าง 1366, 390 และ 320 พิกเซล ไม่พบปุ่ม ช่องปรับค่า ตาราง หรือ select ล้นจอ
- ตรวจภาพหน้าจอเกมวงจร ตารางพันธุกรรม และสายใยอาหาร ไม่พบข้อผิดพลาด JavaScript ระหว่างการทดสอบ

รันทดสอบตรรกะด้วย Node.js:

```sh
node tests/game-regression.mjs
node tests/lab-regression.mjs
```

สภาพแวดล้อมที่ใช้ทำงานนี้ไม่มี `node` ใน PATH จึงรันไฟล์ทดสอบผ่าน Node runtime ของเครื่องมือ ส่วนการตรวจเบราว์เซอร์ใช้ Playwright กับ Edge ในเครื่อง เพราะ Browser ในแอปไม่พร้อมเชื่อมต่อ
