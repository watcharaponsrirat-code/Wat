# ผลตรวจความพร้อมใช้งาน Science Learning Hub

ตรวจวันที่ 8–9 ตุลาคม 2569 (Asia/Bangkok)

**ผลสรุป: แก้ข้อบกพร่องที่ยืนยันได้และตรวจระบบในเครื่องแล้ว แต่ยังไม่พร้อมเป็นระบบโรงเรียนที่รับรองตัวตนและเก็บผลการเรียนรายบุคคลบนเซิร์ฟเวอร์** ระบบปัจจุบันเป็นเว็บสาธิตที่เก็บข้อมูลในเบราว์เซอร์ ข้อจำกัดด้านบัญชี การสำรองข้อมูล และการตรวจภาพประกอบทั้งคลังยังต้องจัดการก่อนใช้ในลักษณะนั้น

รายงานนี้ประเมินความสอดคล้องของข้อความกับพฤติกรรมโปรแกรม ความถูกต้องของจุดที่ตรวจพบ โครงสร้างข้อสอบ การแสดงผล และชุดเผยแพร่ ไม่ใช่ใบรับรองหลักสูตร คุณภาพข้อสอบเชิงสถิติ หรือมาตรฐานการเข้าถึงเว็บไซต์

## การปรับข้อความวิทยาศาสตร์

ตรวจโครงเนื้อหา 40 บท 319 หัวข้อ และคำอธิบายเสริมตามบท พบและแก้ประเด็นต่อไปนี้:

- การตั้งคำถามทางวิทยาศาสตร์: รองรับการสังเกตและสำรวจ ไม่บังคับว่าทุกคำถามต้องมีตัวแปรที่ผู้ทดลองเปลี่ยน
- โครงสร้างอะตอม: ระบุข้อยกเว้นไฮโดรเจน-1 ซึ่งไม่มีนิวตรอน
- เซลล์พืช: ชี้ว่าเซลล์พืชบางชนิดไม่มีคลอโรพลาสต์
- ออสโมซิส: เปรียบเทียบความเข้มข้นและเงื่อนไขเยื่อเลือกผ่าน แทนปริมาณน้ำรวม โดยอ้างอิงหลักการใน [OpenStax: Passive Transport](https://openstax.org/books/biology-2e/pages/5-2-passive-transport)
- การเกิดผล/เมล็ด และการระเหย/เดือด: แยกนิยามและเงื่อนไขให้ชัด
- การขับถ่าย: แยกของเสียจากเมแทบอลิซึมออกจากกากอาหาร
- กำลัง: ตัวอย่างเปรียบเทียบการขึ้นบันไดระบุมวลและความสูงเท่ากัน
- วงจรไฟฟ้า: ใช้คำอธิบายหน้าสัมผัสสวิตช์แยกจากกัน ลดความกำกวมของคำว่า “สวิตช์เปิด”
- ระบบนิเวศ: ผู้ผลิตสร้างสารอินทรีย์จากสารอนินทรีย์โดยใช้พลังงาน และผู้ย่อยสลายคืนสารอาหาร แต่ไม่ได้ทำให้พลังงานหมุนเวียนเหมือนสาร
- พันธุศาสตร์ในแบบจำลอง: ใช้คำว่าการแยกของแอลลีลคู่หนึ่ง แทนคำที่ปะปนกับการรวมกลุ่มอิสระ
- ข้อสอบ G2U5L2-F01: แก้เงื่อนไขพลังงานรวมคงที่เมื่อไม่มีการถ่ายโอนพลังงานเข้าออกระบบ เพราะระบบปิดยังแลกเปลี่ยนพลังงานได้ ดู [OpenStax: First Law of Thermodynamics](https://openstax.org/books/university-physics-volume-2/pages/3-3-first-law-of-thermodynamics)

การตรวจนี้ไม่ใช่การตรวจเฉลยทุกข้อโดยคณะผู้เชี่ยวชาญ และไม่รับรองว่าทุกภาพหรือแบบจำลองไม่มีข้อผิดพลาดที่ยังตรวจไม่พบ

## ข้อมูลเดิมและรุ่นข้อสอบ

- แบบฝึกพื้นฐาน/ประยุกต์ใช้รุ่น 2: เก็บชุดรุ่นก่อนและคำตอบใน previousState แล้วสร้างชุดใหม่ โดยคง XP และสถานะผ่าน กลไกนี้เก็บชุดก่อนหน้าหนึ่งชุด

## สิ่งที่ยังต้องจัดการก่อนใช้งานจริง

1. **ระบบบัญชีและผลการเรียนกลาง:** บัญชีตัวอย่างตรวจใน JavaScript ไม่มีการยืนยันตัวตนหรือสิทธิ์ฝั่งเซิร์ฟเวอร์ ข้อมูลในเบราว์เซอร์แก้ไขได้ จึงใช้เป็นผลการเรียนทางการหรือข้อมูลนักเรียนข้ามอุปกรณ์ไม่ได้ ต้องออกแบบ backend, บัญชีรายคน, สิทธิ์ครู/นักเรียน และการสำรอง/กู้คืนข้อมูล
2. **การตรวจทานทางวิชาการ:** ต้องแก้และอนุมัติภาพ 17 ภาพก่อนนำกลับมา ตรวจภาพที่เหลือและเฉลยครบคลังโดยผู้สอน/ผู้เชี่ยวชาญ การทดสอบโปรแกรมไม่ทดแทนการตรวจนี้
3. **การเข้าถึง:** ข้อสอบ O-NET ต้นฉบับส่วนใหญ่เป็นภาพ คำบรรยายยังไม่ทดแทนโจทย์/แผนภาพทั้งหมดสำหรับโปรแกรมอ่านหน้าจอ และยังไม่ได้ทดสอบทุกกิจกรรมด้วยคีย์บอร์ด/เทคโนโลยีช่วยเหลือ จึงยังไม่รับรอง WCAG
4. **สภาพแวดล้อมจริง:** ยังไม่ได้ทดสอบโฮสต์จริง เครือข่ายโรงเรียน หรืออุปกรณ์นักเรียนทั้งหมด ผลโหลด 1,000 ผู้ใช้จากรายงานเดิมเป็นเครื่องทดสอบภายใน ไม่ควรใช้รับรองจำนวนผู้ใช้จริง
5. **ขนาดไฟล์:** ภาพ PNG สำหรับเปิดขนาดเต็มทำให้ assets ทั้งชุดมีขนาดมาก ควรประเมินพื้นที่โฮสต์และการส่งข้อมูลตามการใช้งานจริงก่อนเผยแพร่
