# แบบฝึกหัดวิทยาศาสตร์

อัปเดตผลตรวจล่าสุด: [รายงานความพร้อมใช้งาน วันที่ 9 ตุลาคม 2569](readiness-audit.md)

## ขอบเขตงาน

- ครบ 40 บทเรียน มีคลังพื้นฐาน 318 ข้อ และประยุกต์ 240 ข้อ
- แบบพื้นฐานสร้างจากหัวข้อและคำอธิบายในบทเรียน โดยปรับคำอธิบายบางหัวข้อและยกเว้นเนื้อหาเสริมที่ไม่ใช้ประเมิน
- แบบประยุกต์ใช้สถานการณ์ที่เขียนแยกตามบทใน `assets/exercises/grade1.js`, `grade2.js` และ `grade3.js`
- แต่ละระดับสุ่ม 6 ข้อพร้อมสลับตัวเลือก ระดับ O-NET Challenge ใช้คลังวิเคราะห์และ O-NET เดิม
- ข้อสอบท้ายบทใช้คลังคำถามแต่งใหม่แยกจากแบบฝึก 20 ข้อต่อบท รวม 800 ข้อ ในรุ่น 2 ดู [ผังข้อสอบท้ายบท](final-exam-blueprint.md) และ [ผลปรับปรุงข้อสอบ](final-exam-update.md); สัดส่วน 5/6/5/4 เป็นของรุ่นเดิม

## คำตอบและความคืบหน้า

ต้องตอบครบและถูกทุกข้อเพื่อรับสถานะผ่าน แต่เลือกไปกิจกรรมอื่นได้ทันทีโดยไม่ต้องผ่านก่อน เมื่อผ่านแล้วปุ่มคำตอบและปุ่มตรวจจะปิดใช้งาน แต่ยังอ่านเหตุผลได้ การเริ่มชุดใหม่จะเปิดให้ฝึกใหม่โดยคง XP ที่ได้รับไว้ ดูการปรับการนำทางล่าสุดใน `navigation-audit.md`

คำตอบและลำดับข้อคงอยู่หลังโหลดใหม่ แบบฝึกพื้นฐานและประยุกต์ใช้ state version 2 หากพบชุดรุ่นก่อนจะเก็บใน `previousState` แล้วสร้างชุดใหม่ โดยคงสถานะผ่านและ XP เดิม ผู้ที่เคยผ่านยังไปต่อได้ ระดับ O-NET Challenge คงชุดเดิมไว้

## ผลตรวจในรอบทำงานนี้

- `tests/exercise-regression.mjs`: ผ่านครบ 120 ชุดใน 40 บท ครอบคลุมทั้งสามระดับ การตอบไม่ครบ/ตอบผิด การแสดงเหตุผล การล็อกคำตอบหลังผ่าน การโหลดใหม่ การเริ่มชุดใหม่ และการกดไปยังแบบฝึกถัดไปหรือข้อสอบท้ายบท
- ตรวจโครงสร้างคลังพื้นฐานและประยุกต์: ตัวเลือกไม่ซ้ำ คำตอบอยู่ในตัวเลือก มีคำอธิบายและรหัสหัวข้อที่อยู่ในบทนั้น
- ตรวจการย้ายชุดพื้นฐานเก่า: เก็บชุดเดิม สถานะผ่าน และ XP
- `tests/game-regression.mjs`: ผ่าน 120 เกมใน 40 บท
- `tests/lab-regression.mjs`: ผ่าน 40 บท

การทดสอบข้างต้นใช้ DOM จำลองและเรียก event handlers ไม่ใช่การตรวจภาพหน้าจอหรือการยืนยันความถูกต้องเชิงวิชาการทุกข้อ ในรอบนี้ Browser ในแอปเชื่อมต่อไม่ได้ จึงยังไม่ได้ตรวจการแสดงผลแบบฝึกบนเบราว์เซอร์จริง

รันทดสอบด้วย Node.js:

```sh
node tests/exercise-regression.mjs
node tests/game-regression.mjs
node tests/lab-regression.mjs
```

เครื่องนี้ไม่มี `node` ใน PATH จึงรันผ่าน Node runtime ของเครื่องมือ
