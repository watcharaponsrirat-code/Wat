# ฝึกข้อสอบ O-NET จริง

เพิ่มส่วนฝึกข้อสอบจริงท้ายหน้าแบบฝึกระดับ 3 (O-NET Challenge) โดยใช้รายการอ้างอิงเดิมใน `assets/exercises/onet-originals.js` จำนวน 66 ข้อ ครอบคลุม 29 จาก 40 บท ปีการศึกษา 2559–2568

- เปิด PDF ต้นฉบับ สทศ. ที่หน้าที่ระบุ พร้อมลิงก์หน้ารวมข้อสอบและเฉลย ต้องเชื่อมต่ออินเทอร์เน็ต และโปรแกรมอ่าน PDF บางตัวอาจไม่ข้ามไปหน้าที่ระบุ
- ตอบด้วยหมายเลข 1–4 ตามต้นฉบับ ไม่สลับตัวเลือก ไม่เผยแพร่ข้อความโจทย์หรือภาพซ้ำ
- ตรวจคำตอบทีละข้อและแสดงบันทึกอธิบายหลังตรวจ เปลี่ยนคำตอบได้โดยซ่อนผลตรวจเดิม
- เก็บคำตอบและสถานะตรวจใน `onetOriginals` ภายในความคืบหน้ารายผู้ใช้และบทเรียน ไม่เพิ่ม XP และไม่เปลี่ยนผลชุด Challenge
- บทที่ยังไม่มีรายการจับคู่แสดงข้อความแจ้ง และยังฝึกชุด Challenge ที่แต่งใหม่ได้ตามเดิม

แหล่งอ้างอิงย้ายจาก `tmp/onet/sources.json` มาไว้ใน `assets/exercises/onet-sources.js` เพื่อไม่พึ่งโฟลเดอร์ชั่วคราว ข้อมูลเฉลยและการจับคู่ใช้จากไฟล์ที่เตรียมไว้ก่อนรอบนี้ ไม่ได้ตรวจความถูกต้องเชิงวิชาการกับ PDF ใหม่ทั้งหมด

## การตรวจสอบ

`tests/onet-regression.mjs` ผ่านครบ 66 ข้อ: รหัสไม่ซ้ำ หัวข้อมีจริง ลิงก์ตรงหน้าที่ระบุ ซ่อนเฉลยก่อนตรวจ ตอบผิด/ถูก เปลี่ยนคำตอบ โหลดความคืบหน้ากลับ และคง XP/ชุด Challenge เดิม ทดสอบบทที่ไม่มีรายการด้วย

`tests/exercise-regression.mjs` ผ่าน 120 ชุดใน 40 บท รวมการตรวจข้อสอบท้ายบท 20 ข้อ การบันทึกคำตอบ การทำซ้ำ และการรักษาความคืบหน้าเดิม

ทดสอบด้วย DOM จำลองผ่าน Node runtime ในเครื่อง ยังไม่ได้ตรวจภาพหน้าจอ เนื่องจาก Browser ในแอปตอบว่า `Browser is not available: iab` และยังไม่ได้ตรวจลิงก์ภายนอกทั้งหมดในรอบนี้
