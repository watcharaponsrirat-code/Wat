# ฝึกข้อสอบ O-NET จริง

แสดงส่วนฝึกข้อสอบจริงก่อนชุดฝึกแต่งใหม่ในหน้าแบบฝึกระดับ 3 (O-NET Challenge) โดยใช้รายการอ้างอิงเดิมใน `assets/exercises/onet-originals.js` จำนวน 66 ข้อ ครอบคลุม 29 จาก 40 บท ปีการศึกษา 2559–2568

- แสดงภาพโจทย์ ตาราง ภาพประกอบ และตัวเลือกจาก PDF ภายในหน้าเว็บ ไม่ต้องเปิด PDF ก่อนตอบ เก็บไฟล์ WebP ในโปรเจกต์และโหลดภาพเมื่อใกล้เลื่อนถึง
- ขยายภาพในกรอบที่เลื่อนแนวนอนได้บนมือถือ และย่อกลับให้พอดีหน้าจอได้ ข้อความจากกระดาษสแกนยังเป็นภาพ ไม่ใช่ข้อความที่เลือกคัดลอกหรือให้โปรแกรมอ่านหน้าจออ่านได้ทั้งหมด
- ตอบด้วยปุ่มหมายเลข 1–4 ตามภาพต้นฉบับ ไม่สลับตัวเลือก แสดงคำตอบที่เลือกและสีผลตรวจ มีตัวนับจำนวนข้อที่ตอบและตรวจถูก
- คงลิงก์ PDF ต้นฉบับ สทศ. พร้อมหน้าอ้างอิงและหน้ารวมข้อสอบ/เฉลย หากโหลดภาพไม่ได้จะแสดงวิธีเปิดต้นฉบับ
- ตรวจคำตอบทีละข้อและแสดงบันทึกอธิบายหลังตรวจ เปลี่ยนคำตอบได้โดยซ่อนผลตรวจเดิม
- เก็บคำตอบและสถานะตรวจใน `onetOriginals` ภายในความคืบหน้ารายผู้ใช้และบทเรียน ไม่เพิ่ม XP และไม่เปลี่ยนผลชุด Challenge
- บทที่ยังไม่มีรายการจับคู่แสดงข้อความแจ้ง และยังฝึกชุด Challenge ที่แต่งใหม่ได้ตามเดิม

แหล่งอ้างอิงย้ายจาก `tmp/onet/sources.json` มาไว้ใน `assets/exercises/onet-sources.js` เพื่อไม่พึ่งโฟลเดอร์ชั่วคราว ข้อมูลเฉลยและการจับคู่ใช้จากไฟล์ที่เตรียมไว้ก่อนรอบนี้ ไม่ได้ตรวจความถูกต้องเชิงวิชาการกับ PDF ใหม่ทั้งหมด

สร้างภาพด้วย `scripts/render-onet-images.py` (PyMuPDF และ Pillow) จาก PDF ใน `tmp/onet` และเก็บขนาดภาพไว้ใน `assets/exercises/onet-images.js` ตรวจภาพแยกรายข้อครบ 66 ภาพเทียบกับหน้าต้นฉบับเพื่อให้ไม่มีคำถามข้างเคียงหรือข้อความถูกตัด โดยคงลายน้ำเดิมไว้

## การตรวจสอบ

`tests/onet-regression.mjs` ตรวจครบ 66 ข้อ: รหัสไม่ซ้ำ หัวข้อมีจริง ไฟล์ WebP มีครบ แสดงภาพในหน้าเว็บก่อนชุดแต่งใหม่ ลิงก์ตรงหน้าที่ระบุ ซ่อนเฉลยก่อนตรวจ ตอบผิด/ถูก เปลี่ยนคำตอบ โหลดความคืบหน้ากลับ และคง XP/ชุด Challenge เดิม ทดสอบบทที่ไม่มีรายการด้วย

`tests/exercise-regression.mjs` ผ่าน 120 ชุดใน 40 บท รวมการตรวจข้อสอบท้ายบท 20 ข้อ การบันทึกคำตอบ การทำซ้ำ และการรักษาความคืบหน้าเดิม

`tests/onet-browser.py` ใช้ Playwright กับ Chrome แบบ headless เพื่อตรวจการโหลดภาพทั้ง 66 ข้อ การตอบผิด/ถูก การโหลดความคืบหน้ากลับ การขยาย/ย่อภาพ ความกว้างจอ 1366/390/320 พิกเซล และข้อความเมื่อโหลดภาพไม่สำเร็จ Browser ในแอปยังตอบว่า `Browser is not available: iab` จึงใช้ Chrome ในเครื่องแทน ไม่ได้ตรวจลิงก์ภายนอกทั้งหมดในรอบนี้
