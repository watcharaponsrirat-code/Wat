# ผลตรวจระบบ Science Learning Hub

วันที่ตรวจ: 6 ตุลาคม 2569 (Asia/Bangkok)

อัปเดตข้อสอบท้ายบท: ปรับเป็นคลังแยก 800 ข้อ ครบ 40 บท พร้อมเฉลยทุกข้อและเก็บชุดที่ค้างเดิม ดู [ผลปรับปรุงและการตรวจข้อสอบ](final-exam-update.md) และ [ผังข้อสอบรายบท](final-exam-blueprint.md) ผล “ผ่าน” ในรายงานระบบนี้หมายถึงการทำงานของโปรแกรม ไม่ใช่การรับรองคุณภาพข้อสอบเชิงสถิติ

## ข้อผิดพลาดที่แก้

1. หลังออกจากระบบ ปุ่มเข้าสู่ระบบไม่มี event handler เนื่องจาก `render()` กลับออกก่อนผูกปุ่ม แก้ให้ผูกปุ่มทุกครั้งที่แสดงหน้าเข้าสู่ระบบ และยกเลิกการผูกซ้ำในการเปิดเว็บครั้งแรก
2. ชื่อผู้ใช้ที่เป็นคุณสมบัติสืบทอดของ JavaScript (`toString`, `constructor`, `__proto__`) ผ่านเงื่อนไขบัญชีได้ แก้ให้ตรวจเฉพาะชื่อที่ประกาศใน `USERS`
3. ความคืบหน้าของทุกบัญชีใช้ key เดียวกัน แยกเป็น `slh_v163_<user>_<lesson>` ข้อมูลเดิมใน `slh_v162_<lesson>` นำมาใช้ต่อเฉพาะบัญชีนักเรียนเดิม `M20105` และคัดลอกเมื่อบันทึกครั้งถัดไป โดยเก็บข้อมูลเก่าไว้ บัญชีครูเริ่มบันทึกแยก การ reset สำหรับทดสอบไม่กระทบอีกบัญชี

## การตรวจต่อและปรับชุดทดสอบ (6 ตุลาคม 2569)

- พบการโหลดไฟล์ JavaScript ล้มเหลวด้วย `net::ERR_CONNECTION_REFUSED` จากเซิร์ฟเวอร์ทดสอบบน Windows ส่งผลให้หน้าเข้าสู่ระบบไม่แสดงในบางรอบ
- เพิ่ม `request_queue_size` เป็น 128 ในเซิร์ฟเวอร์ของ `tests/system-browser.py` และ `tests/onet-browser.py` เพื่อรองรับการเชื่อมต่อพร้อมกันขณะโหลดหน้า
- เพิ่มการบันทึก `requestfailed` ในรายงานตรวจระบบ เพื่อแสดงสาเหตุเครือข่ายโดยตรง แทนการเห็นเพียงข้อผิดพลาด JavaScript ที่ตามมา
- การปรับครั้งนี้อยู่ที่ชุดทดสอบ ไม่ได้เปลี่ยนโค้ดบทเรียนหรือข้อมูลความคืบหน้าของผู้ใช้
- ผล Chrome หลังปรับ: ผ่าน 1,200 กรณีหน้าจอ, ตัวควบคุม Simulation 84 ตัว, ภาพเนื้อหา 319 ภาพ และการส่งข้อสอบ 3 ครั้ง; รายงาน `tmp/system-audit.json` มี `findings: []`
- O-NET ใน Chrome หลังปรับ: ผ่าน 66 ข้อที่ความกว้าง 1366, 390 และ 320 พิกเซล รวมการตอบผิด/ถูก โหลดใหม่ ขยายภาพ และข้อความสำรองเมื่อภาพหาย; ไม่มี page error
- รันไฟล์ `tests/*regression.mjs` ทั้ง 7 ไฟล์จบด้วย exit code 0 ครอบคลุมบัญชี แบบฝึก เกม การนำทาง O-NET และ Simulation (รวม entry point เดิมของ lab)
- เซิร์ฟเวอร์มีข้อความ `ConnectionAbortedError` บางรายการระหว่างรอบตรวจที่ผ่าน โดยไม่ปรากฏข้อผิดพลาดในผลตรวจหน้าเว็บ ข้อความฝั่งเซิร์ฟเวอร์นี้ยังไม่ได้ปรับให้เงียบ

## ขอบเขตที่ควรทราบ

- บัญชี `M20105` และ `teacher` เป็นบัญชีตัวอย่างที่ตรวจรหัสในหน้าเว็บ ยังไม่มีระบบยืนยันตัวตนบนเซิร์ฟเวอร์
- ความคืบหน้าเก็บใน localStorage ของเบราว์เซอร์นั้น ไม่ซิงก์ข้ามเครื่อง และการล้างข้อมูลเว็บไซต์จะลบความคืบหน้า
- O-NET จริงมี 66 ข้อใน 29 บท ส่วน 11 บทยังมีเฉพาะชุดฝึกแต่งใหม่
- การตรวจนี้ยืนยันการทำงานและความสอดคล้องของข้อมูลกับโปรแกรม ไม่ใช่การตรวจทานความถูกต้องเชิงวิชาการของทุกข้อความหรือทุกเฉลย และไม่ได้ตรวจบริการภายนอกทุกลิงก์
