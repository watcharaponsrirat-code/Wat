# ผลตรวจระบบ Science Learning Hub

วันที่ตรวจ: 6 ตุลาคม 2569 (Asia/Bangkok)

## ข้อผิดพลาดที่แก้

1. หลังออกจากระบบ ปุ่มเข้าสู่ระบบไม่มี event handler เนื่องจาก `render()` กลับออกก่อนผูกปุ่ม แก้ให้ผูกปุ่มทุกครั้งที่แสดงหน้าเข้าสู่ระบบ และยกเลิกการผูกซ้ำในการเปิดเว็บครั้งแรก
2. ชื่อผู้ใช้ที่เป็นคุณสมบัติสืบทอดของ JavaScript (`toString`, `constructor`, `__proto__`) ผ่านเงื่อนไขบัญชีได้ แก้ให้ตรวจเฉพาะชื่อที่ประกาศใน `USERS`
3. ความคืบหน้าของทุกบัญชีใช้ key เดียวกัน แยกเป็น `slh_v163_<user>_<lesson>` ข้อมูลเดิมใน `slh_v162_<lesson>` นำมาใช้ต่อเฉพาะบัญชีนักเรียนเดิม `M20105` และคัดลอกเมื่อบันทึกครั้งถัดไป โดยเก็บข้อมูลเก่าไว้ บัญชีครูเริ่มบันทึกแยก การ reset สำหรับทดสอบไม่กระทบอีกบัญชี

## ขอบเขตที่ควรทราบ

- บัญชี `M20105` และ `teacher` เป็นบัญชีตัวอย่างที่ตรวจรหัสในหน้าเว็บ ยังไม่มีระบบยืนยันตัวตนบนเซิร์ฟเวอร์
- ความคืบหน้าเก็บใน localStorage ของเบราว์เซอร์นั้น ไม่ซิงก์ข้ามเครื่อง และการล้างข้อมูลเว็บไซต์จะลบความคืบหน้า
- O-NET จริงมี 66 ข้อใน 29 บท ส่วน 11 บทยังมีเฉพาะชุดฝึกแต่งใหม่
- การตรวจนี้ยืนยันการทำงานและความสอดคล้องของข้อมูลกับโปรแกรม ไม่ใช่การตรวจทานความถูกต้องเชิงวิชาการของทุกข้อความหรือทุกเฉลย และไม่ได้ตรวจบริการภายนอกทุกลิงก์
