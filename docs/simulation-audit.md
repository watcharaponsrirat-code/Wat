# Simulation เฉพาะบทเรียน

แทนหน้าแล็บเดิมด้วย Simulation ที่เขียนด้วย JavaScript และ SVG จำนวน 40 บท บทละหนึ่งกิจกรรมเน้นแนวคิดที่ระบุด้านล่าง ไม่มีการเขียนคำตอบ คำถามทดสอบ คะแนน XP หรือเกณฑ์ผ่าน นักเรียนปรับค่า สลับตัวเลือก เล่นเวลา หยุด และเริ่มใหม่ได้ตามกิจกรรม

มีตัวควบคุมรวม 84 ตัว ใช้งานด้วยเมาส์ สัมผัส หรือแป้นพิมพ์ ไม่เรียก AI หรือบริการภายนอกขณะทดลอง ภาพใช้โมเดลเฉพาะเรื่อง ไม่ใช่ภาพสำเร็จรูปเดียวกันทุกบท

## การเก็บข้อมูลและความก้าวหน้า

- เก็บค่าของแต่ละบทใน progress.simulation โดยแยกจากข้อมูลแล็บเดิม
- ข้อมูลแล็บเดิมและ XP ที่เคยได้รับไม่ถูกลบ ไม่ย้ายสถานะผ่านเดิมมาเป็นคะแนน Simulation
- แถบกิจกรรมแสดงเปิดแล้ว/ทดลองแล้วเท่านั้น ไม่แสดงผ่านหรือไม่ผ่านสำหรับ Simulation
- ความก้าวหน้าใหม่คิดจากอ่านจบ 20% เกม 30% แบบฝึก 30% และข้อสอบ 20% จึงครบ 100% ได้โดยไม่ต้องทดลอง Simulation
- แนะนำ Simulation หลังอ่านเนื้อหา แต่เลือกข้ามได้ ไม่มีเงื่อนไขก่อนทำกิจกรรมอื่น
- ค่าที่ทดลองคงอยู่เมื่อเปลี่ยนหน้าและโหลดใหม่ เริ่มใหม่คืนค่าเริ่มต้น ปุ่มเล่นเวลาเริ่มเมื่อกดเท่านั้นและหยุดเมื่อออกจากหน้า
- เก็บรหัส stage เดิม lab เพื่อให้ลิงก์และ resume ของนักเรียนเดิมกลับมาหน้า Simulation ได้

## ขอบเขตทางวิทยาศาสตร์

แต่ละกิจกรรมระบุสมมติฐานข้างภาพ โมเดลเชิงตัวเลข เช่น ความหนาแน่น ความเข้มข้น แรง พลังงาน คลื่น แสง และวงจร ใช้ความสัมพันธ์พร้อมหน่วยและเงื่อนไข ส่วนโมเดลชีววิทยา สิ่งแวดล้อม และการออกแบบเป็นภาพหรือค่าตัวอย่าง ไม่ใช้พยากรณ์ข้อมูลจริง

ใช้หลักข้างขึ้นข้างแรมตาม [NASA Moon Phases](https://science.nasa.gov/moon/moon-phases/) คือส่วนสว่างที่เห็นเปลี่ยนตามมุมมอง ไม่ใช่เงาโลกบัง แนวคิดการสำรวจการแพร่และวงจรเทียบกับ [PhET Diffusion](https://phet.colorado.edu/en/simulations/diffusion) และ [Circuit Construction Kit](https://phet.colorado.edu/en/simulations/circuit-construction-kit-dc) โค้ดและภาพในเว็บนี้เขียนใหม่ ไม่ได้ฝังหรือคัดลอก simulation ของแหล่งเหล่านั้น

## การตรวจ

- simulation-regression: 40 บท 245 กรณีตัวควบคุมและขอบเขต ไม่มี NaN/Infinity ทุกตัวควบคุมเปลี่ยนผล เก็บค่า รีเซ็ต และคงข้อมูลเก่า
- ตัวอย่างตรวจสูตร: ความหนาแน่น 1 g/cm³ ความเข้มข้น 10% การกระจัด 10 m พลังงานศักย์/จลน์ 50 J ตาราง Aa × Aa การสะท้อนกลับหมด ดวงจันทร์มืด/เต็มดวง กระแสอนุกรม/ขนาน และพลังงาน 2 kWh
- simulation-browser: Edge แบบ headless ทดสอบ 84 ตัวควบคุม ทุกบทที่กว้าง 1366/390/320 px ตรวจเล่น–หยุดเวลา รีเซ็ต เก็บค่าหลังโหลดใหม่ และหยุด timer เมื่อเปลี่ยนหน้า
- ตรวจภาพรวมทั้ง 40 แบบจำลอง และหน้าจอวงจรบนคอมพิวเตอร์/การแพร่บนมือถือ
- ชุดทดสอบ navigation, exercise 120 ชุด และ game 120 กระดานผ่าน

Browser ในแอปไม่พร้อม จึงใช้ Edge ในเครื่อง การตรวจนี้ไม่ใช่การรับรองเนื้อหาโดยผู้เชี่ยวชาญทุกสาขา

รันด้วย Node.js:

```sh
node tests/simulation-regression.mjs
node tests/navigation-regression.mjs
node tests/game-regression.mjs
```

ไฟล์ tests/lab-regression.mjs เป็น entry point เดิมที่เรียกชุดทดสอบ Simulation แทน ส่วน simulation-browser.mjs export ฟังก์ชัน checkSimulationsInBrowser(page) สำหรับใช้กับ Playwright page
