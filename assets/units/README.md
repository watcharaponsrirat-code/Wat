# ภาพประจำหน่วยการเรียนรู้

สร้างใหม่ด้วย imagegen ในตัวสำหรับหน้ารวมหน่วย ม.1–ม.3 รวม 21 หน่วย (6 / 8 / 7)
สไตล์ภาพสามมิติสีสด ชวนสำรวจ ใช้หัวเรื่องตรงตามหลักสูตรใน index.html

- `G1U1.png` เป็นต้น: ภาพต้นฉบับ
- `G1U1.jpg` เป็นต้น: ภาพย่อ 320 × 320 สำหรับหน้าเว็บ
- `manifest.json`: รหัสชั้น หน่วย ชื่อเรื่อง และตำแหน่งไฟล์
- `generation.jsonl`: คำสั่งสร้างภาพและตำแหน่งต้นฉบับจากเครื่องมือ
- `gallery.html`: ดูภาพทุกหน่วยและเปิดต้นฉบับ

หลังเพิ่มภาพ ให้รัน `powershell -NoProfile -ExecutionPolicy Bypass -File assets/units/prepare-web-images.ps1` จากโฟลเดอร์โปรเจกต์เพื่อเตรียมภาพย่อ
